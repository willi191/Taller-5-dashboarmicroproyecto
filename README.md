# Entregables individuales — Microtaller de satisfacción

Proyecto de William David Vivas. Datos ficticios autorizados para fines académicos.

- `public/index.html`: dashboard interactivo con 4 KPI, 3 gráficos y filtros.
- `data/respuestas_satisfaccion.csv`: 30 registros.
- `analysis/analisis_satisfaccion.py`: código reproducible.
- `docs/Documentacion_APA_Microtaller.docx`: documento APA con los criterios.
- `evidence/`: captura y guion para video de máximo 3 minutos.
