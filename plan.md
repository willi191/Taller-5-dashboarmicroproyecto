# Plan — Dashboard de satisfacción

## Dirección visual
- **Cuaderno de Campo Digital** (probabilidad elegida: 0.08): interfaz académica inspirada en fichas de investigación, papel técnico y anotaciones editoriales.
- **Principios:** lectura clara, contraste sobrio, evidencia visible y exploración directa.
- **Paleta:** verde profundo #214E45 para confianza y rigor; dorado #E7A93B para destacar hallazgos; crema #F7F4EC como papel de trabajo.
- **Interacción:** filtros sencillos y actualización inmediata de KPI, gráficos y tabla.
- **Tipografía:** Alegreya Sans para encabezados y sistema sans-serif para datos.

## Estructura
- `public/index.html`: dashboard y lógica interactiva.
- `data/respuestas_satisfaccion.csv`: 30 registros ficticios autorizados.
- `analysis/analisis_satisfaccion.py`: proceso reproducible de análisis.
- `evidence/`: captura y apoyo audiovisual.
- `docs/`: documentación APA.
